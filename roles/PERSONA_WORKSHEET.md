# Student persona worksheet

The course requires the student to write each of the three analyst personas without AI. Replace each baseline analyst file in your own words. Keep all six parts below.

1. Identity: who the role is, in two sentences.
2. How it reads a company: what it reads first and what it ignores.
3. What it is given: name the graph state it can read. Give it nothing else.
4. Criteria: what it scores. Give each criterion a number and a line or tag.
5. What would change its view: one item in the next filing.
6. Output: name the report part it owns. End with `Insight:` and a supported claim that the release's first paragraph does not state. Give the exact source line.
