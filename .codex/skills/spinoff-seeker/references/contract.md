# Seeker contract

Input: a start date and the student-authored `week4/student_inputs/factors.json`.

Deterministic work: search EDGAR; save the filing trail; establish parent, distribution date, ratio, and transferred items; read prices; compute declared factor points; and print the rank.

Output: a dated registry and screen. Each number must cite a filing, a facts record, a printed computation, or the factors file. A search hit is not proof of a spinoff. An information statement that describes a parent distribution is proof.

If required evidence or data is absent, report `not available` or `not known`. Never estimate it.

The last line must be: `Screens, not recommendations.`
