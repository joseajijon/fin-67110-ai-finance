# Spinoff Seeker

Read `references/contract.md` before you run the seeker.

1. Run `scripts/run_seeker.py --start YYYY-MM-DD`.
2. Treat every search result as a candidate until a filing proves that a parent distributed shares of a business.
3. Read the student-authored factor file. Do not invent a missing factor, direction, weight, or window.
4. Keep each established fact with its filing, section, and date.
5. If price data is unavailable, write `not available` and finish the other work.
6. End every screen with `Screens, not recommendations.`

Do not use a model to establish a filing fact, compute a point, or estimate a missing number.
