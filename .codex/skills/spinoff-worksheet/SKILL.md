# Spinoff Worksheet

Read `references/contract.md` before you build a worksheet.

1. Confirm that the student completed `week4/student_inputs/worksheet_method.json` and `investor_persona.md` by hand.
2. Run `scripts/build_worksheet.py --facts FACTS.json --output WORKSHEET.md`.
3. Cite every filing fact by filing, section, and date.
4. Mark each figure as historical, pro forma, or reported after the spin.
5. Print owner cash flow as after-tax earnings plus depreciation minus capital spending.
6. Print the low and mid value calculations from the student's declared method and rates.
7. Write `not known` for a value that the filings do not establish.
8. Use the persona only for why the name may be cheap and what would change the view.

Do not say that the work is done if a reported number lacks filing, facts-file, computation, or configuration evidence.
